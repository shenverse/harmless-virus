# Harmless Virus - 视觉系恶作剧程序

> 一个完全无害的全屏视觉恶作剧程序，模拟黑客入侵终端效果，**不修改、不删除、不加密任何文件**。

## 效果预览

- 全屏黑色背景 + 绿色终端文字快速滚动
- 红色警告弹窗随机弹出
- 屏幕抖动 + 屏幕闪烁效果
- 底部倒计时「勒索倒计时」
- 视觉冲击力拉满，但实际什么都不做

## 安全声明

⚠️ **这是一个 100% 无害的视觉恶作剧程序**

- ❌ 不删除任何文件
- ❌ 不加密任何文件
- ❌ 不修改注册表
- ❌ 不联网
- ❌ 不收集任何信息
- ✅ 按 `ESC` 键立即退出
- ✅ 关闭窗口直接结束进程

## 快速开始

### 方式一：直接运行 Python 脚本

```bash
python app/main.py
```

### 方式二：打包成 EXE

```bash
python build/build_exe.py
```

生成的 EXE 在 `dist/` 目录下。

## 操作说明

| 按键 | 功能 |
|------|------|
| `ESC` | 立即退出程序 |
| 关闭窗口 | 直接结束 |

│   └── exit_handler.py # 退出处理
